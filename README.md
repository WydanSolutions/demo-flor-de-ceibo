# Demostración · Sistema de gestión para Flor de Ceibo y Tu Estilo Vale

Demostración de un sistema de gestión para tiendas de ropa, desarrollado por
**Wydan Solutions**.

- **Todos los datos son inventados.** No hay información real de ninguna clienta,
  proveedor ni venta.
- Funciona por completo en el navegador: no hay servidor ni base de datos.
- Se entra eligiendo la tienda y después la persona: no hace falta contraseña.

Cada persona que abre la página trabaja con su propia copia de los datos de ejemplo,
guardada solo en su navegador. Con «Configuración → Reiniciar la demostración» vuelve
todo al principio.
